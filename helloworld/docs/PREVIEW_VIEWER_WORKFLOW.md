# プレビューとビュワーの関係

このアプリでは、**プレビューが正（マスター）**で、ビュワーはその結果を表示する先です。

## 想定フロー（プレゼンテーター）

1. 左のファイル一覧から表示したいファイルを選ぶ
2. 中央のプレビューで内容を確認する
3. プレビュー上で拡大率・回転・ページなどを調整する
4. その状態をビュワーへ送って観客に見せる

## 表示モードごとの動作

- `操作中に自動表示 = ON`
  - プレビュー操作がリアルタイムでビュワーへ反映される
  - プレビュー自体はビュワーの状態で上書きしない

- `操作中に自動表示 = OFF`
  - プレビューだけで調整できる
  - `ビュワーに表示` ボタンを押したタイミングで、現在のプレビュー状態をビュワーへ送る

## ビュワーウィンドウが閉じている場合

- 自動表示時・手動表示時（`ビュワーに表示`）のどちらでも、
  表示前にビュワーウィンドウを再生成してから反映する
- そのため、誤ってビュワーを閉じても表示操作を再開できる
