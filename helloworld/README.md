# Tauri Media Viewer

Tauri + React で構成されたメディアビューワアプリです。

## 開発

```bash
npm install
npm start
```

## テスト

テストの実行方法は [TESTING.md](./TESTING.md) を参照してください。

```bash
npm run test:run   # フロントエンド
npm run test:rust  # Rust
npm run test:all   # すべて
```
